# Essentia Technologies Challenge

Challenge proposed by the Essentia Group as part of the selection process for the Fullstack Developer position.

## Task Manager

A complete task management system developed with:

- Angular (Frontend)
- Node.js + TypeScript
- Express (Backend)
- MySQL

## Architecture

Frontend (Angular SPA) consuming a RESTful API.
